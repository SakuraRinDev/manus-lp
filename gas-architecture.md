# Google Apps Script の仕組み

## 全体構成図

```
┌─────────────────────────────────────────────────────────────────┐
│                     Google Apps Script                           │
│                                                                   │
│  ┌───────────────────────────────────────────────────────────┐  │
│  │  Code.gs (スクリプトファイル)                              │  │
│  │                                                             │  │
│  │  const CONFIG = { MODEL_NAME: '...' }                      │  │
│  │                                                             │  │
│  │  ┌─────────────────────────────────────────────────────┐  │  │
│  │  │ 【保存だけで反映される部分】                        │  │  │
│  │  │                                                       │  │  │
│  │  │  function onOpen() { }          ← メニュー作成      │  │  │
│  │  │  function checkCompliance() { } ← 内部処理         │  │  │
│  │  │  function approveRows() { }     ← 内部処理         │  │  │
│  │  │  function setupTriggers() { }   ← トリガー設定     │  │  │
│  │  │                                                       │  │  │
│  │  │  ▼ これらはスプレッドシート内で実行される          │  │  │
│  │  └─────────────────────────────────────────────────────┘  │  │
│  │                                                             │  │
│  │  ┌─────────────────────────────────────────────────────┐  │  │
│  │  │ 【デプロイしないと反映されない部分】                │  │  │
│  │  │                                                       │  │  │
│  │  │  function doGet(e) {            ← Webアプリの入口  │  │  │
│  │  │    return JSON.stringify(...);                       │  │  │
│  │  │  }                                                    │  │  │
│  │  │                                                       │  │  │
│  │  │  ▼ これは外部からアクセスされる公開URL            │  │  │
│  │  └─────────────────────────────────────────────────────┘  │  │
│  └───────────────────────────────────────────────────────────┘  │
│                                                                   │
│  保存 (Ctrl+S) → 上の部分に反映                                  │
│  デプロイ       → 下の部分に反映                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 実行パターン別の図

### パターン1: スプレッドシート内での実行（保存のみで動く）

```
┌──────────────────┐
│ スプレッドシート │
│                  │
│  ユーザーが      │
│  メニュー選択    │
│  or トリガー発動 │
└────────┬─────────┘
         │
         ▼
┌─────────────────────────────┐
│ Google Apps Script          │
│                             │
│ function onOpen() { }       │  ← 保存すればすぐ反映
│ function checkCompliance()  │  ← 保存すればすぐ反映
│ function approveRows()      │  ← 保存すればすぐ反映
│                             │
│ CONFIG.MODEL_NAME を使う    │  ← 保存すればすぐ反映
└─────────────────────────────┘

✅ 保存だけでOK
❌ デプロイ不要
```

### パターン2: Webアプリとしての実行（デプロイが必要）

```
┌──────────────┐
│ ブラウザ     │
│ (index.html) │
└──────┬───────┘
       │
       │ fetch(API_URL)
       ▼
┌────────────────────────────────────────┐
│ デプロイされたWebアプリURL             │
│ https://script.google.com/.../exec     │
└──────────────┬─────────────────────────┘
               │
               ▼
┌─────────────────────────────────────────┐
│ Google Apps Script (デプロイ版)         │
│                                         │
│ function doGet(e) {                     │  ← デプロイしないと反映されない
│   const works = getApprovedWorks();     │  ← 内部で呼ばれる関数は保存だけでOK
│   return JSON(...);                     │
│ }                                       │
└─────────────────────────────────────────┘

❌ 保存だけではダメ
✅ デプロイが必要（doGet関数を変更した場合のみ）
```

## 具体例で理解する

### ケース1: モデル名を変更

```javascript
const CONFIG = {
  MODEL_NAME: 'openai/gpt-4o'  →  'anthropic/claude-3.5-sonnet'
};

function checkCompliance() {
  // CONFIG.MODEL_NAME を使う
  fetch(API_URL, { model: CONFIG.MODEL_NAME });
}
```

**どこで使われる？**
- `checkCompliance()` → メニューから実行 → スプレッドシート内

**必要な操作:**
- ✅ 保存
- ❌ デプロイ不要

---

### ケース2: doGet関数のレスポンスを変更

```javascript
function doGet(e) {
  return JSON.stringify({
    success: true,
    works: works,
    newField: 'new value'  // ← これを追加
  });
}
```

**どこで使われる？**
- `doGet()` → 外部URL経由 → Webアプリ

**必要な操作:**
- ✅ 保存
- ✅ デプロイ必要

---

### ケース3: 内部関数を追加

```javascript
function approveSelectedRows() {  // ← 新しい関数
  sheet.getRange(...).setValue('APPROVED');
}
```

**どこで使われる？**
- メニューから実行 → スプレッドシート内

**必要な操作:**
- ✅ 保存
- ❌ デプロイ不要

---

### ケース4: doGetから呼ばれる関数を修正

```javascript
function doGet(e) {
  const works = getApprovedWorks();  // ← この関数を呼んでいる
  return JSON.stringify({ works: works });
}

function getApprovedWorks() {
  // ← この関数の中身を変更
  return filteredWorks;
}
```

**必要な操作:**
- ✅ 保存
- ❌ デプロイ不要（doGet自体は変更していないから）

```
└─────────────────────────────────────────────────┘
```

## デプロイの仕組み

```
Apps Scriptエディタで保存
         │
         ▼
┌─────────────────────┐
│ 開発版 (最新)       │ ← 常に最新のコード
│                     │
│ メニューやトリガー  │
│ はここから実行      │
└─────────────────────┘

デプロイボタンを押す
         │
         ▼
┌─────────────────────┐
│ 本番版 (スナップ)   │ ← デプロイした時点のコード
│                     │
│ WebアプリURL経由    │
│ はここから実行      │
└─────────────────────┘
```

デプロイとは「**本番版のスナップショットを更新する**」ということ。

## 今回のあなたのケースまとめ

| やりたいこと | 必要な操作 |
|-------------|-----------|
| 欠けている関数を追加 | 保存のみ |
| メニューを使えるようにする | 保存のみ |
| モデルを変更 | 保存のみ |
| WebアプリAPIの動作 | **変更なし** → デプロイ不要 |
