# Manus Works Gallery - Google連携セットアップガイド

## 概要

このガイドでは、Google FormとGoogle Apps Scriptを使って
作品投稿・表示システムをセットアップする手順を説明します。

## 1. Google Formの作成

### 1.1 新規フォームを作成

1. [Google Forms](https://forms.google.com) にアクセス
2. 「空白」をクリックして新規フォームを作成
3. フォームタイトルを「Manus Works 作品投稿」などに設定

### 1.2 質問を追加（この順序で）

| 順番 | 質問タイトル | 形式 | 必須 | 備考 |
|------|-------------|------|------|------|
| 1 | 作品タイトル | 記述式（短文） | ◯ | |
| 2 | 作者名 | 記述式（短文） | ◯ | |
| 3 | カテゴリ | プルダウン | ◯ | 下記の選択肢 |
| 4 | 作品説明 | 段落（長文） | ◯ | |
| 5 | 画像URL | 記述式（短文） | | 任意 |
| 6 | 作品URL | 記述式（短文） | | 任意 |
| 7 | Manus URL | 記述式（短文） | | 任意 |

### 1.3 カテゴリの選択肢

プルダウンに以下の選択肢を追加：

- Apps & Tools
- Documents
- Data & Analysis
- Creative
- Others

### 1.4 フォームURLを取得

1. 右上の「送信」ボタンをクリック
2. リンクアイコン（🔗）をクリック
3. 「URLを短縮」にチェック
4. URLをコピー

## 2. スプレッドシートの設定

### 2.1 回答をスプレッドシートに連携

1. フォームの「回答」タブをクリック
2. 緑色のスプレッドシートアイコンをクリック
3. 「新しいスプレッドシートを作成」を選択
4. 「作成」をクリック

### 2.2 承認列を追加（オプション）

手動で作品を承認してから公開したい場合：

1. スプレッドシートを開く
2. I列（9列目）のヘッダーに「承認済み」と入力
3. 公開したい行に「TRUE」または「承認済み」と入力

※承認列がない場合は、全ての投稿が自動で表示されます

## 3. Google Apps Scriptの設定

### 3.1 スクリプトエディタを開く

1. スプレッドシートを開く
2. メニュー「拡張機能」→「Apps Script」をクリック

### 3.2 コードを貼り付け

1. 既存のコードを全て削除
2. `gas/Code.gs` の内容を貼り付け
3. 「Ctrl+S」で保存

### 3.3 テスト実行

1. 関数選択で「testGetWorks」を選択
2. 「実行」ボタンをクリック
3. 初回は権限の承認が必要
   - 「権限を確認」→「詳細」→「〇〇（安全ではないページ）に移動」→「許可」
4. ログに作品データが表示されればOK

### 3.4 Webアプリとしてデプロイ

1. 右上の「デプロイ」→「新しいデプロイ」をクリック
2. ⚙️（歯車）→「ウェブアプリ」を選択
3. 設定:
   - 説明: `Manus Works API v1`
   - 次のユーザーとして実行: `自分`
   - アクセスできるユーザー: `全員`
4. 「デプロイ」をクリック
5. **Web App URL** をコピー（重要！）

例: `https://script.google.com/macros/s/xxxxx/exec`

## 4. LPへの設定

### 4.1 API URLを設定

`script.js` を編集:

```javascript
const GALLERY_CONFIG = {
  API_URL: 'https://script.google.com/macros/s/xxxxx/exec', // ここにURLを貼り付け
  // ...
  demoMode: false  // デモモードをOFFに
};
```

### 4.2 Google Form URLを設定

`index.html` を編集:

```html
<a href="https://forms.gle/xxxxx" target="_blank" ...>
  作品を投稿する
</a>
```

## 5. 動作確認

1. ブラウザでLPを開く
2. Galleryセクションに作品が表示されることを確認
3. 「作品を投稿する」ボタンからフォームが開くことを確認
4. テスト投稿してスプレッドシートに反映されることを確認

## トラブルシューティング

### 作品が表示されない

1. ブラウザのコンソール（F12）でエラーを確認
2. Apps Scriptのログを確認
3. CORS エラーの場合はデプロイ設定を確認

### スクリプトの更新後

1. 「デプロイ」→「デプロイを管理」
2. 「新しいバージョン」を作成
3. 新しいURLが発行される場合は、`script.js` を更新

### 列の順序が違う場合

`Code.gs` の `COLUMNS` オブジェクトを
実際のスプレッドシートの列順序に合わせて調整してください。
